## Ejercicio 2 de la semana 2

1. Se ha creado un entorno virtual para esta semana.
2. Se ha creado un proyecto con ``uv init --package --vcs none --name wine_quality_project``.
3. Se han instalado una serie de dependencias de **ejecución** con el comando ``uv add dependencia``.
4. Se han instalado otras dependencias exclusivas de **desarrollo** con ``uv add --dev dependencia``.
5. Se han incorporado los tres ficheros situados en la carpeta ``semana2/starter``.
   - El archivo ``train.py`` se encuentra situado en la carpeta ``src\wine_quality_project\``.
   - El archivo ``test_train.py`` en la carpeta ``tests\``.
   - El archivo ``WineQT.csv``  en la carpeta ``data\raw\``.
